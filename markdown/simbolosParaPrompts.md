# Tabela em Markdown com os códigos Alt para símbolos úteils na escrita de prompts

| Símbolo | Código Alt    |
| ------- | ------------- |
| **├**   | `Alt` + `195` |
| **─**   | `Alt` + `196` |
| **└**   | `Alt` + `192` |

**Como usar:**

- Deixar o **Num Lock** ativado;
- segurar a tecla **Alt**;
- Digitar o número correspondente no **teclado numérico** e, em seguida, soltar a tecla Alt.
